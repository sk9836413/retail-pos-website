# भारत GST, ई-इनवॉइस और ई-वे बिल

इसके लिए **TGS POS - India GST** ऐप ज़रूरी है।

## POS पर GST

1. **रिटेल POS सेटअप** (TGS POS Setup): **भारत GST चालू** (India GST Enabled) चालू करें। CGST, SGST/UTGST, IGST और सेस देय खाते भरें, और एक
   **0% वाला VAT उत्पाद पोस्टिंग समूह** (VAT Prod. Posting Group with 0%) जो स्टेटमेंट बिक्री दस्तावेज़ों पर उपयोग होता है, ताकि GST केवल GST खातों में पोस्ट हो।
2. **GST समूह** (GST Groups): GST % और क्षतिपूर्ति सेस % (उदाहरण के लिए 5, 12, 18, 28 + सेस)।
3. **आइटम** (Items): GST समूह और HSN/SAC कोड।
4. **स्टोर** (Stores): GSTIN और 2 अंकों का GST राज्य कोड (उदाहरण के लिए 27 महाराष्ट्र)।
5. **ग्राहक** (Customers): GSTIN। दूसरे राज्य के ग्राहक पर CGST + SGST की जगह IGST लगता है (आपूर्ति का स्थान)।

POS पर कीमतों में GST शामिल होता है। रसीदें **टैक्स इनवॉइस** (TAX INVOICE) (वापसी के लिए **क्रेडिट नोट** (CREDIT NOTE)) के रूप में प्रिंट होती हैं, जिन पर स्टोर GSTIN, ग्राहक GSTIN,
आपूर्ति का स्थान और HSN-वार GST सारांश होता है। स्टेटमेंट पोस्टिंग GST को देय खातों में दर्ज करती है।

## ई-इनवॉइस (IRN)

ई-इनवॉइसिंग B2B बिक्री (GSTIN वाले ग्राहक) के लिए है, अगर आपके टर्नओवर के कारण यह ज़रूरी है।

1. किसी GST Suvidha Provider (GSP) से API एक्सेस लें। ClearTax पहले से जुड़ा है; NIC JSON स्वीकार करने वाले दूसरे GSP *अन्य GSP* (Generic GSP) से काम करते हैं।
2. **GST ई-इनवॉइस सेटअप** (GST E-Invoice Setup): *चालू* (Enabled), प्रदाता, एनवायरनमेंट (sandbox / production), owner ID / यूज़र नाम, और **API टोकन / सीक्रेट सेट करें** (Set API Token / Secret)।
   अन्य GSP के लिए URL और response path भी भरें।
3. **बिक्री पूरी होने पर IRN बनाएँ** (Generate IRN when the sale is finished) चालू करें।

जब कोई B2B बिक्री पूरी होती है, तो IRN बनता है और रसीद पर **IRN, Ack नं. (Ack No.), Ack तारीख (Ack Date) और हस्ताक्षरित QR कोड (signed QR code)** प्रिंट होते हैं।
अगर GSP से संपर्क नहीं हो पाता, तो रसीद इनके बिना प्रिंट होती है और जॉब कतार फिर से कोशिश करती है (**बाकी ई-इनवॉइस पंजीकृत करें** (Register Pending E-Invoices))।
**ई-इनवॉइस लॉग** (E-Invoice Log) हर अनुरोध दिखाता है। लेन-देन कार्ड पर: **ई-इनवॉइस रद्द करें** (Cancel E-Invoice) (24 घंटे के अंदर) और **ई-वे बिल बनाएँ** (Generate E-Way Bill)
(दूरी, परिवहन का तरीका, वाहन नंबर या ट्रांसपोर्टर GSTIN)।

जिस रसीद में बेचे और वापस किए गए आइटम दोनों हों, उसका ई-इनवॉइस नहीं बन सकता; वापसी अलग से करें।

## रिटर्न और रिपोर्ट

| रिपोर्ट | उपयोग |
|---|---|
| **GSTR-1 निर्यात (JSON)** (GSTR-1 Export (JSON)) | GST ऑफ़लाइन टूल / पोर्टल के लिए JSON: B2B, B2C बड़े, B2C छोटे, क्रेडिट नोट, HSN सारांश (B2B और B2C), जारी किए गए दस्तावेज़ |
| **GSTR-3B सारांश (Excel)** (GSTR-3B Summary (Excel)) | टेबल 3.1 (टैक्स योग्य बाहरी आपूर्ति, शून्य दर / छूट प्राप्त) और 3.2 (अपंजीकृत व्यक्तियों को अंतर-राज्यीय आपूर्ति) |
| **GST बिक्री रजिस्टर (Excel)** (GST Sales Register (Excel)) | हर POS इनवॉइस, टैक्स योग्य मूल्य, CGST, SGST, IGST और सेस के साथ |
| **GST B2B इनवॉइस** (GST B2B Invoices), **GST HSN सारांश** (GST HSN Summary) | जाँचने के लिए स्क्रीन पर सूचियाँ |

जब किसी कंपनी के कई पंजीकरण हों, तो GSTIN से फ़िल्टर करें। फ़ाइल करने से पहले आँकड़े अपने टैक्स सलाहकार से जाँच लें।
